说明

· 需要 Cloudflare API Token（权限：Zone → DNS → Edit，作用于目标域名的 zone）。
· 申请通过 DNS-01 验证，无需开放 80/443 端口，支持泛域名 *.example.com（泛域名必须与主域名一起申请，如 example.com,*.example.com）。
· 证书与私钥加密存于数据库，同时在 <数据目录>/certs/<id>.crt|.key 落盘。
· 节点编辑 TLS 模式选「外部证书」时可直接引用这里的证书；证书续签后引用节点自动热重载，无需重启。
